# ASOUD ERP Frappe App

افزونه مستقل ASOUD برای حسابداری ایرانی روی ERPNext/Frappe، با معماری هدف
ERPNext v15 و شاخه رسمی `version-15`.

این مخزن لایه اختصاصی ASOUD است و هیچ فایل Core از ERPNext را تغییر نمی‌دهد.
وابستگی به ERPNext از طریق `required_apps = ["erpnext"]` تعریف شده و توسعه، تست
و استقرار این افزونه باید روی ERPNext v15 انجام شود. ارتقا به major بعدی فقط پس
از بررسی سازگاری و ثبت تصمیم معماری جداگانه مجاز است.

## قابلیت‌های نسخه 0.8.0

- تنظیمات تعهدی ASOUD
- گروه تفصیلی
- تفصیلی شناور
- نگاشت حساب به گروه تفصیلی
- تولید خودکار کد تفصیلی
- تولید خودکار کد گروه، کل و معین بر اساس الگوی قابل تنظیم
- API نسخه ۱ برای Flutter
- قرارداد پاسخ یکسان برای تمام APIهای اختصاصی
- API دریافت درخت سرفصل‌ها برای Flutter
- پیش‌نمایش و ایجاد سرفصل با کد خودکار در Backend
- گروه‌های تفصیلی پیش‌فرض و API مدیریت نگاشت حساب معین
- پروفایل یکپارچه اشخاص حقیقی و حقوقی با نقش‌های چندگانه
- همگام‌سازی کنترل‌شده نقش‌های مشتری و تأمین‌کننده با ERPNext
- اعتبارسنجی کد ملی، شناسه ملی و موبایل ایران
- CI برای بررسی قالب کد، کامپایل پایتون و تست قرارداد API
- سند حسابداری دوبل با کنترل قطعی تراز بدهکار و بستانکار
- گردش پیش‌نویس، در انتظار تأیید، تأیید و رد با ثبت دلیل
- تولید و Submit کردن Journal Entry رسمی ERPNext فقط پس از تأیید مدیر حسابداری
- تراز آزمایشی با مانده افتتاحیه، گردش دوره و مانده پایان دوره
- دفتر کل و معین متصل به GL Entry با مانده تجمعی و فیلتر حساب/طرف‌حساب
- راه‌اندازی پایدار و چندشرکتی دفتر، تنظیمات حسابداری و نقش‌های فعال دفتر
- بازیابی وضعیت راه‌اندازی و ادامه از نخستین مرحله ناقص در Flutter

نقش‌های انتخاب‌شده در راه‌اندازی، قابلیت‌های کاری فعال برای هر دفتر هستند و Role یا مجوز کاربران
Frappe را تغییر نمی‌دهند. تخصیص مجوز کاربران همچنان فقط از سازوکار استاندارد Frappe انجام می‌شود.

## نصب

```bash
bench get-app /path/to/asoud-backend
bench --site your-site.local install-app asoud_erp
bench --site your-site.local migrate
```

## بررسی توسعه

```bash
python -m compileall -q asoud_erp
ruff check .
pytest -q
```

CI سبک مخزن، ساختار مستقل افزونه را بررسی می‌کند. تست یکپارچه کامل باید پس از نصب
روی یک سایت واقعی Frappe/ERPNext اجرا شود.

Workflow `ERPNext v15 Integration` نیز روی Pull Request، یک سایت موقت ERPNext شاخه
`version-15` می‌سازد، افزونه را نصب و migrate می‌کند و تست راه‌اندازی شرکت را اجرا می‌کند.
